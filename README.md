# Terra Imperium 🌍

A grand strategy country-and-army simulator on a real Earth globe, spanning **2000 BCE to 2300 CE**. Pick any of 240 nations and take it from the Bronze Age to the space race.

> **Status**: In active development. Terra Imperium is being built on the foundation of an earlier project (a regional Middle-East campaign) that already delivered a fully interactive whole-earth 3D globe, real country/province geography and adjacency, and a deterministic turn engine. Development is now generalizing that foundation into the full global game described below — see the roadmap.

## Vision

- **Any nation, any era** — start as any of the 240 countries already modeled, from 2000 BCE through 2300 CE
- **Five ages** — Bronze Age, Classical Age, Age of Kingdoms, Age of Gunpowder, Modern Age — each gating new resources, buildings, units and tech
- **Civilization-style game speed** — Fast / Normal / Marathon, controlling years per turn
- **Deep resource economy** — Gold and manpower (HR) always matter; Copper, Iron and Oil unlock and stay relevant by age
- **Region management** — control, infrastructure, defenses, factories, and a full Civ-style building tree per region
- **A real army sim** — per-region armies, unit classes with hard counters, morale/organization, promotions, generals, supply and logistics
- **Naval warfare and island conquest** — coastlines and sea lanes derived from the game's own geography data, with naval reach expanding by age
- **Paradox-depth systems** — stability & unrest, supply & attrition, war exhaustion, casus belli, evolving government types
- **A Modern Age space race** — satellites, missiles, and a mission ladder to the Moon, Mars and beyond
- **World history events** — the event-popup system carries over from the original project, rewritten to cover all 240 nations instead of one
- **Tiered AI with real counter-building behavior**, five difficulty levels
- **Native iOS and Android app** (via Capacitor), plus async multiplayer alongside offline skirmish

## Tech Stack

- **React 18** — UI framework with hooks
- **react-globe.gl / three.js** — interactive 3D Earth globe rendering
- **Tailwind CSS** — utility-first styling
- **Lucide React** — icon library
- **Vite** — build tool and dev server
- **Context + Reducer** — state management
- **Vitest** — test suite
- **Capacitor** (planned) — native iOS/Android packaging

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/yaniv89/terra-imperium
cd terra-imperium
npm install
npm run dev
```

The game will open at `http://localhost:3000`

### Build for Production

```bash
npm run build
npm run preview
```

### Tests and Lint

```bash
npm test
npm run lint
```

## Architecture Notes

- **Deterministic engine**: `src/engine/resolveTurn.js` is a pure function driven by a seeded PRNG (`src/utils/rng.js`). Given the same seed and action list, it always produces the same resulting state — the property that makes cheap, cheat-proof multiplayer possible later.
- **Real geography**: all 240 countries and their admin-1 provinces are modeled from real TopoJSON data, including real land-border adjacency, generated by scripts in `scripts/geo/`.
