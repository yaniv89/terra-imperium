Terra Imperium
UI and UX sketches, world play and RTS battles
Every screen drawn at 844x390, a phone held landscape, the reference screen. Desktop uses the same layouts with more room.
FIVE RULES
1. The map or the battle owns the screen; panels slide in from the right and close.
2. One thumb reach: primary actions bottom right, tab rail on the right edge.
3. Markers only when they answer a question (selected, damaged, in danger).
4. Every number has a reason on tap.
5. Command or Auto is always one tap, never buried.
