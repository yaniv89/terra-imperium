## Merge routine that works
1. `git merge --no-edit <branch>` (local branches; no fetch needed, the worktrees share refs).
2. `npm run lint`.
3. `npm run test:quick`, or vitest on the touched folders.
4. Rerun any failure alone. Load timeouts are common; they pass alone.
5. `npm run build`.
6. `git push origin claude/integration` and `git push origin HEAD:main`.

To back out a merge, use `git reset --keep HEAD~1`, never `--hard`. The two dirty files `scripts/blender/render_sprites.py` and `scripts/blender/validate_unit.py` are the user's unknown WIP; never commit them, so never use `git commit -a`.
