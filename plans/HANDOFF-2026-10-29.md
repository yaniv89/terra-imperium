## 5. After the go: the routine

1. Start the lanes as cloud sessions. Use `create_session` with source claude/integration, outcome_branch claude/<lane>, and `extra_allowed_tools: ["mcp__claude-code-remote__send_message"]`.
   - From a local PC session without the claude-code-remote tools, run each brief as its own local session or worktree instead. The worktree recipe is in CLAUDE.md.
2. Verify ponytail from each lane's transcript (list_events): the start hook prints "PONYTAIL MODE ACTIVE", or the whole SKILL.md is printed with `cat`. Replace a lane that fakes it.
3. Lanes cannot always message the lead. Every tick, poll:
   - `git log origin/claude/integration..origin/claude/<lane>`
   - `list_sessions`
   - the "For the lead" section of each idle lane's report
   Answer design calls the same tick.
4. Merge one lane at a time:
   - Run engine-rules-reviewer for engine and sim diffs, and fix real findings.
   - Merge into integration.
   - Run `npm run lint`, then `npm run test:related` on the merge's files, or `npm run test:quick`.
   - Push integration only when no CI is running there, since a push cancels the run. Batch doc commits. Back up local work to `claude/integration-next`.
5. When integration CI is green and the user has given the go, push main. Check that the Cloudflare deploy workflow succeeds.
6. Next grade round, on November money from 1 Nov (newcomer, civ-veteran, warmonger, battle-commander):
   - Opus, the limit set, caps summing under the month's budget. Dispatch with workflow `claude-content.yml`, job `human-playtest`, ref claude/integration.
   - Inputs: persona, scene, slices, size, limit, max_usd, play_model opus.
   - Append the grades to the dashboard.
7. Keep a heartbeat. ScheduleWakeup is lost on a session restart, so re-arm it first thing every turn. `create_trigger` and `send_later` into the lead session return ACCESS_DENIED on this account.
