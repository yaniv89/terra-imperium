## Incidents and lessons from this session (lead's own account)
- The first version of `scripts/prune-worktrees.mjs` deleted a running lane's fresh worktree (U31), because
  a new worktree's HEAD is an integration commit and counted as "merged". Fixed in ac8086d3: it now skips
  HEADs on integration's first-parent line and anything outside `.claude/worktrees` and `ti-*`. Always dry run.
- `git worktree remove --force` follows a lane's `node_modules` junction and wiped the main checkout's
  `node_modules` once; always `rmdir` the junction first (the script does this).
- The C: drive fell to 4.8 GB free; pruning ~100 merged worktrees freed about 302 GB (315 GB free at pause).
- With 8 or more sessions on this PC, tests time out under load. Rerun failures alone before calling them
  real. One real failure this session (the AI war test after U47) was found by bisect and fixed with the
  lane's version (d387ab8e).
- The app refuses `user_asked` session starts on turns begun by a lane event; then propose a card and start
  it on the user's next message. Two sessions failed to start with `config-hooks-refused`; restarting worked.
- Usage limits stop Opus lanes mid-work; they commit WIP and must be told to resume.

## Merge routine that works
1. `git merge --no-edit <branch>`; resolve conflicts (save and setup version clashes: keep both changes,
   bump the later one).
2. `npm run lint`, `npm run test:quick` (or the full `npx vitest run` for engine-wide changes); rerun
   failures alone.
3. `npm run build`, then delete `dist/`.
4. `git push origin claude/integration`, then `git push origin HEAD:main` (separate bare commands).
5. `node scripts/prune-worktrees.mjs` (read the dry run) then `--go`.
