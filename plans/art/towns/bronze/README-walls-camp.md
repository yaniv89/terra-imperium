# Terra Imperium — Bronze Age continuation

Four combined 2D reference sheets: walls-small, walls-medium, walls-big, colony-camp. Bronze Age was assumed because the preceding session was unavailable. No Blender work.

These are generated concept references, not the spec-compliant final export package. Each PNG is 1254 x 1254 with views combined. The spec requires separate 4096 x 4096 files per view. Exact geometry, consistent orthographic projections and dimensions require further validation; in particular the camp top/front panels retain perspective and the big-wall tower counts vary across panels.
