# Kingdoms Age palaces and walls

Five 2D combined reference sheets: palace-small (earthen motte with wooden keep), palace (stone keep), walls-small, walls-medium, walls-big (stone curtain rings with round towers). No Blender work. Each result saved individually upon completion; at most four generation requests running concurrently.

Each PNG is 1254 x 1254 with seven views combined, not the separate 4096 x 4096 view files specified for final handoff. Exact tower counts, strict orthographic projections, consistent geometry and dimension labels need validation before modelling.
