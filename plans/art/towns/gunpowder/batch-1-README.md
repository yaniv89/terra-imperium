# Gunpowder Age towns — batch 1

Five 2D combined reference sheets: town-small-a, town-small-b, town-medium-a, town-medium-b, town-big-a. European brick/stucco towns with varied tile, slate and mansard roofs, cobbled lanes, clock towers, baroque church, windmills and a small bastion in big A. Central palace reserves left empty. No Blender work. Each result saved individually upon completion, with at most four concurrent generation requests.

PNG sheets are 1254 x 1254 with seven views combined, not the separate 4096 x 4096 view exports required for final handoff. Exact geometry, building counts, orthographic accuracy, dimensions and cross-view consistency need validation before modelling.
