# Classical Age town references — batch 1

Four 2D combined reference sheets: town-small-a (Roman), town-small-b (Han Chinese), town-medium-a (Roman), town-medium-b (Han Chinese). Small footprint 40 x 40 m; medium footprint 60 x 60 m. Centres reserved for palaces. No Blender work.

Generated PNGs are 1254 x 1254 with seven views combined; these are concept references, not the spec-required separate 4096 x 4096 view files. Projections, building counts, layout consistency and dimensions require validation before modelling. Some panels labeled orthographic retain perspective.
